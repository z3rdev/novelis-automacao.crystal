# Inicializacao do Novelis Cargo Hub

A arquitetura em uso e: **um backend local por computador**, com o SQLite
compartilhado em `\\192.168.254.250\rede\Publico\novelis-automacao\novelischamado.sqlite`.

O guia atual e [hub-tauri-local.md](hub-tauri-local.md).
Use `INICIAR-BACKEND.cmd` em cada computador. O nome antigo
`INICIAR-BACKEND-SERVIDOR.cmd` foi mantido como atalho de compatibilidade e
agora chama o inicializador local. Nao e necessario iniciar uma API no servidor.
